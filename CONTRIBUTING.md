# Contributing to Roblox VSCode

First off, thank you for using **Roblox VSCode**! Since this is a finished product distribution, we do not accept code contributions at this time. However, your feedback and bug reports are invaluable to the project.

## How can you contribute?

### 1. Reporting Bugs
If you find a bug, please check the [Issues](https://github.com/CodingJeffRoblox/Roblox-VSCode/issues) tab on GitHub to see if it has already been reported. If not, open a new issue and include:
*   A clear, descriptive title.
*   The version of the VS Code extension and Roblox Studio you are using.
*   Steps to reproduce the problem.
*   Screenshots or logs from the Activity Log in the Roblox plugin.

### 2. Feature Requests
Have an idea for a new feature or shortcut? Open an issue on GitHub and label it as `enhancement`. We review every suggestion!

### 3. Sharing Your Setup
We love to see what you're building! Share your projects and show how the sync is helping your workflow.

---

## Technical Support
If you have questions about how to set up the sync or if your files aren't appearing:
1.  Read the **Troubleshooting** section in the [README](https://github.com/CodingJeffRoblox/Roblox-VSCode#readme).
2.  Ensure your **Game Settings -> Security** has **Allow HTTP Requests** enabled.
3.  Check that the VS Code server is active (**Ctrl+Shift+R**).
